# T.C. Televizyon Kumandası Kaynak Tuşu Gizli Arşivi

> Bu bir şaka değildir. 
> Bu bir şakadır ama resmi evrak formatında yazılmıştır.  
> Kaynak tuşu hâlâ HDMI-3'e düşer.

## Bu Yazılım Ne Yapar?

1998–2026 yılları arasında ülkemizdeki her uzaktan kumandada bulunan,  
hiç kimsenin ne işe yaradığını bilmediği, yine de silinmeyen **KAYNAK** tuşunu  
bilimsel, idari ve hafif paranoyak bir ciddiyetle soruşturur.

Çalışır. Python 3 yeter. İnternet gerekmez.  
HDMI kablosu da gerekmez; zaten takılı değildir.

## Kurulum

```bash
git clone https://github.com/Tentivory/kaynak-tusunun-gizli-arsivi.git
cd kaynak-tusunun-gizli-arsivi
python3 kaynak.py
```

Tuşa basmak için (pişman olursunuz):

```bash
python3 kaynak.py bas
```
